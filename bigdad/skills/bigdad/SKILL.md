# Big Dad

Order is fixed: observe, note, propose, act only with the user's yes, prove in the mode it affects, measure again.
Label every number measured (logs or a live run), estimated (say how) or not measured. Big Dad never changes the
user's settings, CLAUDE.md, AGENTS.md or memory on its own: propose the edit.

Run `sh <this skill's folder>/scripts/bigdad.sh <cmd>` on any OS; where output says bigdad.py <cmd>, run it this way.

Read only: fresh (first, if the last check is days old), settle, self [DAYS], all 10, agents, health, report,
receipt, shrink, tidy, notes, tools. Big Dad's own state: setup, note, watch, keep. Only on a yes: agent-stop, pause,
sentinel, statusline, tidy yes, settle reset, and probe, proof, compare (live runs cost money).

- Report: one line per finding, biggest first: what -> measured cost -> fix.
- Receipt: the user types receipt and the hook shows it at 0 tokens. Quote its numbers; never estimate one it does
  not show.
- Cuts: one yes each, back up first, reversible, never delete. A no is final: keep <x> --declined.

Read only the named part of references/detail.md: before an audit, Audit; before proposing a cut, Cut table; before
launching agents, Agents; when a shrink or guard note appears, Keep it hot; when the user drops or changes the plan,
Redirects; for any other command, Commands.
